# Dropi Matrix Scanner 🚀

Motor de auditoría e inteligencia de ventas para Dropi Colombia en la nube de GitHub Actions.
- **10 Workers en Paralelo** corriendo en Microsoft Azure.
- Escaneo de 60.000 productos en menos de 2 minutos sin bloqueos de IP.
- Detección de ventas en tiempo real, velocidad diaria y cálculo de GMV / CPA.
